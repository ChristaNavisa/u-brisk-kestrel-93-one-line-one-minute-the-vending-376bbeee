# The Snack I Want to Keep

One pickup line, 200 characters at most, as if a vending machine were flirting with a passing human — for the make.fun bounty [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
